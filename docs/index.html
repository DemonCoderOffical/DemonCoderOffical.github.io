NetPlus v0.3 Documentation

About NetPlus

NetPlus is an advanced network toolkit designed for terminal enthusiasts and network analysis. It provides interactive menus, scan modes, and local interface diagnostics.

Available Commands & Features:

  • 1 (General Info / About): Displays tool version and core developer details.
  • 2 (SCAN Mode): Activates the sub-menu for network diagnostics and tools.
    • help: Shows scan examples and available options inside scan mode.
    • 3: Displays local machine Hostname and Local IP details using socket connections.
    • back: Returns to the main terminal menu.
  • exit: Safely exits the NetPlus application.
